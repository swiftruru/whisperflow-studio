# v1.16.6

Greatly expands the list of supported source media formats — `.aac` and many other ffmpeg-decodable audio/video formats are now accepted for import and transcription.

大幅擴充支援的來源媒體格式——新增 `.aac` 以及眾多 ffmpeg 可解碼的音訊/視訊格式，皆可匯入並轉錄。

## Improved / 改善

- **Expand supported media formats from 21 to 64** ([python/config/config.metadata.json](python/config/config.metadata.json), [locales/en/help.json](locales/en/help.json), [locales/zh-TW/help.json](locales/zh-TW/help.json)) — the `supportedMediaExtensions` whitelist is the single source of truth read by both the import filter ([src/main/queue-manager.js](src/main/queue-manager.js)) and the file picker dialog ([src/main/ipc-handlers.js](src/main/ipc-handlers.js)), so previously any file outside the 21-entry list (notably `.aac`) was silently skipped as "Unsupported file format" even though the underlying ffmpeg engine could decode it fine. The list now covers most ffmpeg-decodable container/codec extensions that carry a transcribable audio track — new video: `qt / webm / wmv / asf / mts / mpg / mpe / m1v / vob / ogv / 3gpp / 3gp2 / mxf / rm / rmvb / divx`; new audio: `mp2 / aac / opus / oga / spx / weba / wma / aif / aifc / ac3 / eac3 / dts / amr / awb / au / snd / caf / ape / wv / tta / mpc / voc / gsm / dsf / 3ga / ra / w64`. Each entry was cross-checked against `ffmpeg -demuxers`; obscure formats with no transcribable audio (raw video pipes, console stream formats, subtitle/image demuxers) were intentionally excluded. Help docs updated accordingly.
  **支援格式從 21 種擴充到 64 種** — `supportedMediaExtensions` 白名單是單一來源，同時被匯入過濾（`queue-manager.js`）與檔案選擇對話框（`ipc-handlers.js`）讀取；先前任何不在這 21 項清單內的檔案（尤其是 `.aac`）即使底層 ffmpeg 完全能解碼，仍會被當作「不支援的檔案格式」靜默跳過。清單現已涵蓋絕大多數帶有可轉錄音軌的 ffmpeg 容器/編碼副檔名——新增影片：`qt / webm / wmv / asf / mts / mpg / mpe / m1v / vob / ogv / 3gpp / 3gp2 / mxf / rm / rmvb / divx`；新增音訊：`mp2 / aac / opus / oga / spx / weba / wma / aif / aifc / ac3 / eac3 / dts / amr / awb / au / snd / caf / ape / wv / tta / mpc / voc / gsm / dsf / 3ga / ra / w64`。每一項皆已比對 `ffmpeg -demuxers` 核實；無可轉錄音軌的冷門格式（原始視訊管線、遊戲機串流格式、字幕/影像 demuxer）刻意排除。說明文件同步更新。
