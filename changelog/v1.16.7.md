# v1.16.7

Fixes severe UI jank while dragging files over the Media Directory card — the whole window stayed smooth now instead of stuttering during the drag.

修正拖曳檔案到「媒體資料夾」卡片時整個畫面嚴重卡頓的問題——拖曳過程現在保持順暢，不再頓挫。

## Fixed / 修正

- **Eliminate drag-over repaint thrash on the Media Directory card** ([src/renderer/index.js](src/renderer/index.js), [src/renderer/components/preflight-panel.js](src/renderer/components/preflight-panel.js)) — the `dragover` handler ran `classList.add('drag-over')` on every event (fires 60+ times/second while hovering), and `dragleave` decided whether to clear the highlight via `e.relatedTarget` — which is almost always `null` for OS file drags. The result: as the cursor moved between the card's child elements, `.drag-over` was added and removed on nearly every frame, restarting the blurred `box-shadow` transition and forcing a full-card repaint on the main thread each frame, which stuttered the whole UI. Replaced the `relatedTarget` check with a standard drag-depth counter so the highlight class is set once on enter and cleared once on leave, and made `dragover` only call `preventDefault()` (plus set `dropEffect`) without mutating the DOM. Visual behaviour is unchanged; repaints drop from per-frame to once on enter / once on leave.
  **消除媒體資料夾卡片的拖曳重繪抖動** — `dragover` handler 在每次事件（懸停時每秒觸發 60+ 次）都呼叫 `classList.add('drag-over')`，而 `dragleave` 用 `e.relatedTarget` 判斷是否清除高亮——但 OS 檔案拖曳時 `relatedTarget` 幾乎都是 `null`。結果：游標在卡片各子元素間移動時，`.drag-over` 幾乎每一幀都被加上又移除，反覆重啟帶模糊的 `box-shadow` transition，每幀在主執行緒強制整張卡重繪，拖累整個 UI 頓挫。改用標準的 drag-depth 計數器取代 `relatedTarget` 判斷，讓高亮 class 只在進入時加一次、離開時清一次；並讓 `dragover` 只呼叫 `preventDefault()`（並設定 `dropEffect`）而不再變更 DOM。視覺效果不變，重繪從「每幀」降到「進/出各一次」。
